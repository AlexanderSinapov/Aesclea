# Aesclea Medical System #
The future of medicine.

The following system combines full medical institution administration, patient care and so on. All of this is held by Artificial Intelligence(later called AI).

## THE AI ##
The current alpha version of the solution is already proved concept with world wide known algorithms and AI methods. But, in Aeslcea we introduce for the first time the first ever, working fourier-integral based algorithm
meant to enhance stability, confidence and LLM prospects of the model. We call the Algorithm MED-IACT. Why 'MED' - because we aim to make the work of doctors lighter and softer, to let them rest while assisting a patient. We do not aim to replace them!
